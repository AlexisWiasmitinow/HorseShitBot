🎮 Téléopération & Rosbags

Manette Data Frog

  • Left stick : conduite
  • D-Pad : lift up/down
  • RB / LB : brush / bin door
  • Select : toggle bag perception
  • D-Pad Left : toggle bag mapping
  • A = E-STOP / B = reprise

Enregistrement

  • perception_recorder : caméra couleur + profondeur
  • mapping_recorder : LiDAR + odom + TF
  • Format MCAP dans ~/rosbags/
  • Commande : ros2 bag info ...

Dashboard disponible sur http://<IP_ROBOT>:8080

🧠 Pipeline YOLO

  1. Extraction : scripts/extract_images_from_bag.py
  2. Annotation : LabelImg / Roboflow → format txt YOLO
  3. Entraînement : 
    from ultralytics import YOLO
model = YOLO("yolov8n.pt")
model.train(data="dataset.yaml", epochs=10, imgsz=640)

Métriques clés : mAP50, precision, recall. On valide la chaîne, pas le modèle final.

🧭 Nav2 — Navigation Autonome

Stack

  • AMCL : localisation sur carte statique
  • Planner : NavFn (A* / Dijkstra)
  • Controller : Regulated Pure Pursuit
  • Costmap : global + local
  • Behavior Tree : replanning, recovery

Launch

ros2 launch horseshitbot \
  nav2_bringup_launch.py \
  map:=maps/salle_test.yaml

Fichier clef : config/nav2_params.yaml

👁️ YOLO injecté dans Nav2

camera color → yolo_detector_node → PointCloud2 → obstacle_layer → local_costmap

  • yolo_detector_node lit color + aligned_depth + camera_info
  • Pour chaque bbox YOLO : projection 3D via matrice intrinsèque K
  • Publie /yolo/obstacles (PointCloud2)
  • nav2_params.yaml a la source yolo_obstacles déjà configurée
local_costmap:
  obstacle_layer:
    observation_sources: scan yolo_obstacles
    yolo_obstacles:
      topic: /yolo/obstacles
      data_type: PointCloud2
      marking: true
