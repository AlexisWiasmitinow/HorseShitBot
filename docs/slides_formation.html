🎮 Teleoperation & Rosbags

Data Frog Controller

  • Left stick : driving
  • D-Pad : lift up/down
  • RB / LB : brush / bin door
  • Select : toggle perception bag
  • D-Pad Left : toggle mapping bag
  • A = E-STOP / B = resume

Recording

  • perception_recorder : colour + depth camera
  • mapping_recorder : LiDAR + odom + TF
  • MCAP format in ~/rosbags/
  • Command : ros2 bag info ...

Dashboard available at http://<ROBOT_IP>:8080

🧠 YOLO Pipeline

  1. Extraction : scripts/extract_images_from_bag.py
  2. Annotation : LabelImg / Roboflow → YOLO txt format
  3. Training : 
    from ultralytics import YOLO
model = YOLO("yolov8n.pt")
model.train(data="dataset.yaml", epochs=10, imgsz=640)

Key metrics : mAP50, precision, recall. We validate the pipeline, not the final model.

🧭 Nav2 — Autonomous Navigation

Stack

  • AMCL : localization on static map
  • Planner : NavFn (A* / Dijkstra)
  • Controller : Regulated Pure Pursuit
  • Costmap : global + local
  • Behavior Tree : replanning, recovery

Launch

ros2 launch horseshitbot \
  nav2_bringup_launch.py \
  map:=maps/salle_test.yaml

Key file : config/nav2_params.yaml

👁️ YOLO Injected into Nav2

camera color → yolo_detector_node → PointCloud2 → obstacle_layer → local_costmap

  • yolo_detector_node reads color + aligned_depth + camera_info
  • For each YOLO bbox : 3D projection via intrinsic matrix K
  • Publishes /yolo/obstacles (PointCloud2)
  • nav2_params.yaml already has the yolo_obstacles source configured
local_costmap:
  obstacle_layer:
    observation_sources: scan yolo_obstacles
    yolo_obstacles:
      topic: /yolo/obstacles
      data_type: PointCloud2
      marking: true

🐳 DevContainer Usage

  • Add .devcontainer/devcontainer.json for a reproducible workspace
  • Base image: ros:${ROS_DISTRO}-ros-base
  • Pre-install deps: nav2-bringup, slam-toolbox, ultralytics, realsense2-camera
  • Volume mount workspace + ~/.ros (bags / maps)
  • Jetson users: rely on NVIDIA Docker runtime + --gpus all
// .devcontainer/devcontainer.json excerpt
"image": "ros:jazzy-ros-base",
"runArgs": ["--privileged", "--network=host"],
"postCreateCommand": "rosdep install --from-paths src -y"

Everyone runs the exact same ROS 2 version, tools, and Python packages.
