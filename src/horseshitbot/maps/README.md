# Maps

Place here the maps generated by SLAM Toolbox:

- `map_name.pgm` — map image (occupancy)
- `map_name.yaml` — metadata (resolution, origin, etc.)

## Generate a map

```bash
ros2 service call /slam_toolbox/save_map slam_toolbox/srv/SaveMap "name:
  data: '/home/<user>/maps/salle_test'"
```

## Use the map

Copy the `.pgm` + `.yaml` files into this folder, then:

```bash
# Autonomous navigation with the map
ros2 launch horseshitbot autonomy_launch.py map:=$(ros2 pkg prefix horseshitbot)/share/horseshitbot/maps/salle_test.yaml
```
